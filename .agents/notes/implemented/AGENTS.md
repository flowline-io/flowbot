# Implemented Agent Notes

These notes describe shipped decisions. Follow [the format](../README.md#file-format).

Keep paths, symbols, defaults, and mechanisms current in the same change that alters them. Rewrite stale facts in place; do not append change history. Use the present tense. `## Verification` states present-tense evidence, not an acceptance checklist.

This is not a license to rewrite the *decision*. A reversal of the decision or its rationale requires a new Agent Note and a cross-link.

When a shipped note is unlikely to guide future work, archive it per [archiving](../README.md#archiving) instead of continuing to maintain it.
