Capability and platform skills generated from current CLI command trees and composer specs.

What Skills Mean in Flowbot

Most skills map directly to capability IDs. Platform skills (e.g. workflow, pipeline) are generated from dedicated composer definitions.

Skills are loaded progressively by AI assistants: frontmatter first, full SKILL.md only on demand.

Enable Skills

Skills are generated into docs/skills/. Point your assistant to these folders by capability ID.

Claude Code

# Project-wide
mkdir -p .claude/skills/
ln -sf "$(pwd)/docs/skills/karakeep" .claude/skills/karakeep
ln -sf "$(pwd)/docs/skills/kanboard" .claude/skills/kanboard
ln -sf "$(pwd)/docs/skills/miniflux" .claude/skills/miniflux
ln -sf "$(pwd)/docs/skills/workflow" .claude/skills/workflow
ln -sf "$(pwd)/docs/skills/pipeline" .claude/skills/pipeline

# Global
mkdir -p ~/.claude/skills/
ln -sf "$(pwd)/docs/skills/karakeep" ~/.claude/skills/karakeep
